# AI Disclosure

BJCPid was vibecoded through an AI-assisted development process with OpenAI Codex, directed and reviewed by the repository owner.

The application code, parser heuristics, deterministic matcher, interface, tests, and documentation were substantially produced through that process. Human review, local testing, and iterative correction were used, but this repository should not be treated as professionally audited judging, competition, legal, or production software.

The matcher is intended as a local study and feedback aid. It can surface plausible BJCP style candidates from sensory evidence, but it does not replace trained judging, current BJCP guidance, competition rules, or brewer judgment.

Always verify style text, entry requirements, and competition expectations against the official BJCP materials.
